Plain-language policy

Privacy

Effective 27 August 2026

The CLI stays local

Capture Clock Repair reads photo metadata, filenames, and filesystem timestamps only on your computer. It does not upload photos, paths, metadata, review CSVs, manifests, or sidecars. The CLI contains no telemetry and makes no network requests.

The website

This site uses no advertising, analytics, tracking pixels, third-party fonts, or social widgets. A service worker stores public site files in your browser so documentation and the sample demo work offline.

Licenses and purchases

If you return from checkout with a license token or paste one, the site stores that token and a time-stamped verification result in your browser's local storage. It sends the token only to the Sociobot license verification endpoint. You can erase it by clearing this site's storage. Sociobot/Dodo processes purchase and receipt details as merchant of record; this site does not receive card numbers.

Questions

Open an issue in the project repository for privacy questions or requests.
