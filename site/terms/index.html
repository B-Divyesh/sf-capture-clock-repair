Use and responsibility

Capture Clock Repair proposes metadata corrections. It does not establish when a photo was taken.

Review each proposal, keep backups, and run a dry preview before applying sidecars.

Test sidecars with your catalog software before adding them to your main catalog.

Software license

The source is provided under the MIT License without warranty.

The CLI does not rewrite original photos. It writes adjacent XMP sidecars for approved rows.

Apply refuses existing sidecars. Undo refuses any sidecar changed after creation.

Availability

The CLI works locally after installation. Website availability may occasionally be interrupted.

Future versions may change supported formats, but existing installed versions remain under their published license.

Repair photo capture times with reviewed XMP sidecars.
