The method

A field notebook before a field edit

Separate observation from action. Capture Clock Repair gives uncertain evidence somewhere honest to live.

  1. I

    Inventory

    Read JPEG EXIF, filename clocks, filesystem time, camera make, and model. Group likely sources without changing a byte.

    capture-clock-repair scan ./archive
  2. II

    Review

    Inspect a CSV that distinguishes embedded truth, strong filename guesses, weak fallbacks, and timezone conflicts.

    open clock-review/review.csv
  3. III

    Patch—or undo

    Create adjacent XMP labels only for approved rows. A checksummed manifest can remove unchanged patches later.

    capture-clock-repair apply …

Field instructions

One binary. Three deliberate steps.

Build on macOS, Linux, or Windows with Rust 1.85+. The binary makes no network requests.

Terminal · first survey
$ cargo install capture-clock-repair
$ capture-clock-repair scan ~/Pictures/Trip \
    --output clock-review --timezone +05:30
